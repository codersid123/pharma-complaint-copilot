# AI-Powered Customer Complaint Management System

A pharmaceutical QMS complaint intake and triage module for API & FDF manufacturing.
The complaint form is **fully AI-driven** — every field is populated and edited through
the AI copilot, either by extracting from an uploaded document or by natural-language
instruction. No manual data entry.

**Stack:** React + Redux Toolkit · FastAPI · LangGraph · Groq · PostgreSQL

## Status
